\# Equivalencias estructurales Python ↔ R



\- array de NumPy ('np.array') ↔ vector de R ('c()')

\- DataFrame de pandas ('pd.DataFrame') ↔ tibble / data.frame de R

\- índice desde 0 en Python ↔ índice desde 1 en R

\- filtrado con '\&' entre condiciones entre paréntesis ↔ 'filter(cond1 \& cond2)'
