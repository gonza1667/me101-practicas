\# Tema 2 — Instalación y Configuración de Entornos



Esta carpeta contiene la evidencia de la Tarea 1 y la Tarea 2 del Tema 2 del curso ME101.



\## Contenido



\- \*\*Puelles\_Zapata\_Gonzalo\_Fredy\_Tema2\_Verificacion.ipynb\*\*: notebook de Jupyter que verifica la instalación de Python, pandas y numpy. Se ejecuta con el entorno conda `me101` (Python 3.11), que incluye pandas, numpy, matplotlib, seaborn y jupyterlab.



\- \*\*tema2\_verificacion.R\*\*: script de R que verifica la instalación de R y RStudio, cargando el paquete `tidyverse`. Se ejecuta desde el proyecto de RStudio `ME101\_ProgramacionEstadistica`.



\## Cómo reproducir



1\. Para el notebook: activar el entorno `me101` con `conda activate me101` y abrir con `jupyter lab`.

2\. Para el script de R: abrir el proyecto `ME101\_ProgramacionEstadistica` en RStudio y correr `tema2\_verificacion.R` con `Ctrl+Shift+Enter`.
